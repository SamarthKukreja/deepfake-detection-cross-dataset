What we measure

In-domain scores don't tell the full story.

A detector that scores 0.90 AUC on FaceForensics++ may collapse to near chance on Celeb-DF. This study makes the gap the primary object of measurement — not accuracy on the training distribution.

All five backbones share an identical face-crop pipeline, training recipe, and video-level evaluation code so that differences in results are attributable to architecture and training data, not hyper-parameter tuning.

Main finding

Training diversity beats architecture choice.

ConvNeXt-Tiny has the highest AUC point estimates in Exp 1, Exp 2, and Exp 4, but the edge over ResNet-50 is not significant under paired tests at this single seed. All backbones collapse to near-chance on Exp 3 (Celeb-DF → FF++) — proving training-set coverage dominates.

Pipeline

One fixed face-crop harness, five backbones.

Every configuration shares the same preprocessing, splits, optimizer, augmentation policy, and video-level evaluation code. Only the backbone changes.

1

Sample frames every 10th frame; detect and crop faces with MTCNN (confidence ≥ 0.95, box ≥ 60 px, 20% margin).

2

Assign crops to source-video-disjoint splits. FF++ fakes are kept only when both contributing identities fall in the same split.

3

Fine-tune backbone from ImageNet weights with AdamW, cosine annealing, label smoothing ε=0.05, and progressive unfreezing.

4

At inference, apply 5-view TTA (flip, ±15° rotation, brightness shift) and average crop scores per source video.

5

Compute accuracy, AUC, F1, EER with 1 000-resample bootstrap CIs and paired McNemar tests across backbones.

Limitations

A controlled single-seed comparison, not a final ranking.

Each configuration was trained once with a fixed seed — bootstrap intervals and paired tests quantify uncertainty over held-out videos conditional on that model, not run-to-run variability. The temporal probe uses score statistics after inference and does not model temporal information directly. Exp 3 combines dataset and detector-checkpoint changes. The corruption study covers JPEG, blur, noise, and downscaling, but not adversarial attacks or platform re-encoding.
